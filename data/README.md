# Набор данных Deadlock Atlas

Готовые данные для приложения: герои, предметы, сборки и герои на голосовании.
Собраны из открытого проекта [Deadlock API](https://deadlock-api.com/), русские
названия и описания — из официальной локализации игры (deadlock-wiki/deadlock-data).

| Файл | Что внутри |
| --- | --- |
| `heroes.json` | 40 героев: тип, сложность, теги, лор, характеристики, оружие, 4 способности с улучшениями, подборка популярных предметов, изображения |
| `items.json` | 173 предмета магазина: цена, тир, слот, свойства, уровни улучшений, описание (поле `description_source`: `official` — текст игры, `generated` — собран из эффектов) |
| `builds.json` | по три сборки на героя: название, автор, дата, версия, ID для копирования, группы покупок с ценами и примечаниями, поле `fresh` — самая свежая сборка |
| `upcoming.json` | четыре героя патча City Never Sleeps на голосовании и даты их релизов |
| `meta.json` | дата снимка, версия клиента, патч и счётчики |

Обновление данных:

```bash
python3 tools/fetch_raw.py --out data/raw                        # сырые ответы API
python3 tools/build_dataset.py --raw data/raw --out data         # этот набор
```

В GitHub Actions то же самое делает `.github/workflows/atlas-data.yml`:
снимок складывается в служебную ветку `atlas-data-raw`.
