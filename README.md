# Deadlock Atlas

Бесплатный неофициальный справочник по Deadlock для Windows.
Создатель — Maksim Mishunov (warfaiser).

## Скачать

🌐 Сайт: https://warfaiser.github.io/Deadlock-Atlas/

📥 Приложение для Windows:
https://github.com/warfaiser/Deadlock-Atlas/releases/latest/download/Deadlock-Atlas.exe

## Что нового

- Патч City Never Sleeps: в приложении появились **Буся** и **Крысиный король** —
  способности, предметы, характеристики и сборки.
- **40 героев** вместо 39: обновлены данные всех героев.
- **120 сборок** — по три на каждого героя: две самые популярные за неделю
  и одна самая свежая.
- Описания предметов и способностей — **официальная русская локализация игры**.
  Там, где Valve ещё не перевела строки (Буся, «Запах крови»), стоит пометка
  о переводе проекта.
- Остальные герои патча — Соломон, Сестра Хэрроу, Дохлый Дэнни и Виолетта —
  выходят 9, 13, 16 и 20 октября; порядок определяет голосование игроков.

## Возможности

- 40 героев с изображениями, описаниями, способностями и сборками.
- 120 сборок — по три на каждого героя, с ID для копирования в игру.
- 173 предмета с ценами и характеристиками.
- Поиск, избранное и отметки купленных предметов.
- Работа без интернета.

## Как запустить

1. Скачайте Deadlock-Atlas.exe.
2. Запустите файл двойным щелчком — установка не требуется.

Поддерживается Windows 10/11 x64.
Оставьте около 400 МБ свободного места для запуска.

## Данные и разработка

Набор данных для приложения лежит в каталоге `data/`:

- `heroes.json` — герои, способности с улучшениями, характеристики и оружие;
- `items.json` — 173 предмета магазина с ценами, свойствами и уровнями улучшений;
- `builds.json` — по три сборки на героя (две популярные и одна свежая);
- `upcoming.json` — герои на голосовании и даты их релизов;
- `meta.json` — снимок, версия клиента, патч и счётчики.

Снимок собирается из открытого проекта Deadlock API:

```bash
python3 tools/fetch_raw.py --out data/raw          # сырые ответы API + локализации игры
python3 tools/build_dataset.py --raw data/raw --out data   # готовый набор
```

Воркфлоу `.github/workflows/atlas-data.yml` обновляет снимок автоматически
(ветка `atlas-data-raw`) при изменениях в `tools/`.
