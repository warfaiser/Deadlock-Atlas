# Deadlock Atlas

Бесплатный неофициальный справочник по Deadlock для Windows.
Создатель — Maksim Mishunov (warfaiser).

## Скачать

🌐 Сайт: https://warfaiser.github.io/Deadlock-Atlas/

📥 Приложение для Windows:
https://github.com/warfaiser/Deadlock-Atlas/releases/latest/download/Deadlock-Atlas.exe

## Возможности

- 39 героев с изображениями, описаниями и способностями.
- 117 авторских сборок — по три на каждого героя.
- 173 предмета с ценами и характеристиками.
- Поиск, избранное и отметки купленных предметов.
- Работа без интернета.

## Как запустить

1. Скачайте Deadlock-Atlas.exe.
2. Запустите файл двойным щелчком — установка не требуется.

Поддерживается Windows 10/11 x64.
Оставьте около 400 МБ свободного места для запуска.

## Важно

- Версия приложения: 1.0.1.
- Снимок игровых данных: 04.10.2026.
- Автоматического обновления нет.
- Сборки отобраны по популярности, а не по гарантированному винрейту.
- Файл без цифровой подписи: Windows может показать предупреждение
  о неизвестном издателе. Проверяйте файл перед запуском.
